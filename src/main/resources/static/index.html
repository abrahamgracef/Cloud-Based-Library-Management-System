Review 1 Viva & Presentation Cheatsheet

Core CI/CD Workflow:

Developer → GitHub (Source) → CodePipeline (Orchestrator) → CodeBuild (Build & Test) → CodeDeploy (Deploy) → EC2 (App Server) → RDS PostgreSQL (Data) + S3 (Covers).

Why This Workflow?

Automates software delivery. Code push automatically triggers unit tests and zero-downtime deployment to EC2, eliminating human error and manual server configuration.

CloudWatch vs CloudTrail:

CloudWatch: "What is happening?" (CPU, RAM, logs).
CloudTrail: "Who did what?" (API audit history & security governance).

S3 vs RDS Separation:

Amazon RDS: Structured relational records (books, members, fines).
Amazon S3: Scalable object storage for heavy binary files (book covers).
